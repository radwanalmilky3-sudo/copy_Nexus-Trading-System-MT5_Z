# الدفعة الأولى — 21 أكتوبر 2026 بتوقيت عدن

تم تنفيذ النطاق الذي اعتمده المستخدم، دون تفعيل التداول أو تغيير حساب MT5 أو حذف البيانات.

## التغييرات المثبتة

1. الصفقات: لا يكفي طول القائمة صفرًا لتأكيد عدم وجود صفقات. يشترط وصول لقطة حديثة واتصال حي. عند التعذر تظهر رسالة عدم التحقق وشرطات بدل عدد الصفقات وإجمالي الربح المؤكد.
2. مخاطر البوابة: غياب الحالة أو تقادمها يعرض UNKNOWN، لا NORMAL. لا يحدّث وقت النجاح بسبب طلب فاشل فقط.
3. ذاكرة التداول: الطلب صار GET /api/intelligence/trade-memory مع ترويسة المصادقة. يقرأ metrics.by_session وحقل trades الفعلي. مقاييس Kelly والدولار الناقصة ليست أصفارًا ولا تُشتق من متوسط pips. تظهر غير متاحة. مسار 404 السابق لم يعد مستخدمًا في المكوّن المعدّل.
4. الاختبار التاريخي: عند صفر صفقات تخفى بطاقات تقييم الربحية وتظهر «بيانات غير كافية». لا تغييرات في حساب النتائج الخلفية أو أوامر التداول.

- node --experimental-strip-types --test --test-reporter=dot tests/*.test.mjs: خروج0، 86 اختبارًا. التشغيل السابق بصيغة TAP قبل اختبار عقد المنتج الإضافي أظهر85/85. شمل التشغيل الأخير الاختبار الجديد الثامن.
- node node_modules/typescript/bin/tsc --noEmit: خروج0 بعد آخر تعديل.
- git diff --check: خروج0؛ تحذيرات تحويل LF/CRLF في شجرة العمل الموجودة، لا أخطاء whitespace.
- الاختبار الخاص بعقد المنتج الفعلي فشل أولًا: توقع صف جلسة ولم يستلمه؛ ثم اجتاز بعد دعم trades وعدم اختلاق Kelly أو الدولار.
- الاختبارات السبعة الأولى كُتبت قبل التنفيذ؛ تشغيلها الأول فشل لعدم وجود الوحدة الجديدة، وليس إثباتًا مستقلًا لإعادة إنتاج كل سلوك قديم. الفحص المرئي السابق هو دليل السلوك القديم.
- الواجهة الحالية أثبتت UNKNOWN ورسالة الصفقات المتقادمة وشرطة إجمالي الربح ورسالة عدم كفاية صفقات الاختبار.

- Console المتاح أعاد قائمة أخطاء وتحذيرات فارغة في نقطة التحقق؛ ليست مراقبة Network/HAR كاملة.
