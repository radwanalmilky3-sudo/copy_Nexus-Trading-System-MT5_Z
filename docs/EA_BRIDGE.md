# EA Bridge — ربط MetaTrader 5 بمنظومة Nexus Trader (البندان 3 و4)

> آخر تحديث: 2026-11-04. الحالة: مُختبر حيًا من طرف إلى طرف (11/11 PASS).

## 1. نظرة عامة

```
┌──────────────┐  WebRequest كل 1-3 ثوان   ┌──────────────────────────┐
│  MT5 Terminal │ ── handshake + poll ────▶ │ nexus-api (9000)         │
│ NexusBridgeEA │ ◀──── أوامر JSON ──────── │  /api/ea/handshake       │
│  (هذا المستودع) │ ───── نتائج التنفيذ ───▶ │  /api/ea/poll           │
└──────────────┘                            └────────────┬─────────────┘
                                                         │ ea_commands
                                            ┌────────────▼─────────────┐
                                            │ nexus-executor (9007)     │
                                            │ يكتب أمرًا لكل صفقة ناجحة │
                                            └──────────────────────────┘
```

- التوكن: بادئة `nexus_ea_` + 32 بايت عشوائي (~256 بت). **يُعرض مرة واحدة** عند الإنشاء، ويُخزَّن على الخادم كبصمة **SHA-256** فقط — تسريب قاعدة البيانات لا يسرّب توكنًا صالحًا.
- الربط: أول مصافحة ناجحة تربط التوكن بهوية الطرف (`mt5_login`/`broker`/`server`)؛ أي طرف آخر بنفس التوكن يُرفض 409.
- الإلغاء فوري: `DELETE /api/admin/ea-tokens/{id}` ثم كل المطالبات تُرد 401.
- Idempotency: `command_id` مفتاح فريد؛ التقرير المكرر يُتجاهل، والدورة الواحدة (`poll`) تجمع النتائج + المطالبة الدفعة التالية (حتى 20 أمرًا) في طلب واحد.
- تعافي الأوامر العالقة: أمر `claimed` لم يُبلَّغ عنه خلال 5 دقائق يعود للطابور تلقائيًا، والإكسبيرت يمنع التنفيذ المزدوج عبر سجل محلي.

## 2. إنشاء التوكن (من الداشبورد)

1. سجّل الدخول → تبويب **جسر MT5** (`/nexus/ea-bridge`).
2. أدخل اسمًا للطرف (مثال: `MT5-Laptop`) → **إنشاء توكن**.
3. انسخ التوكن فورًا — لن يُعرض مرة أخرى. (يمكن عمل ذلك برمجيًا: `POST /api/admin/ea-tokens` بمصادقة JWT.)

## 3. إعداد الطرف MT5

1. انسخ `mql5/Experts/NexusBridgeEA.mq5` إلى `MQL5\Experts\` في طرف MT5 (File → Open Data Folder).
2. افتح الملف في MetaEditor واضغط **Compile** (F7) — لا مكتبات خارجية.
3. في MT5: **Tools → Options → Expert Advisors**:
   - فعّل *Allow WebRequest for listed URL*.
   - أضف العنوان الأصلي (origin) **بالضبط** كما سيُستدعى، مثال: `https://nexus.example.com` أو `http://192.168.1.50:9000`.
4. أرفق الإكسبيرت على **شارت واحد** (XAUUSD مثلًا) واضبط المدخلات:
   | المدخل | الوصف |
   |---|---|
   | `InpBaseURL` | عنوان الخادم الأساسي بدون مسار (استخدم `https://` في الإنتاج) |
   | `InpToken` | توكن `nexus_ea_...` من الداشبورد |
   | `InpPollSec` | فترة البوٍل بالثواني (1-3 موصى بها) |
   | `InpTimeoutMs` | مهلة HTTP (5000) |
   | `InpMagic` | الرقم السحري لأوامر الإكسبيرت (لا يمس صفقاتك اليدوية) |
5. فعّل زر **Algo Trading**. سطر الحالة على الشارت يعرض: الربط، آخر بوٍل، عدد الأوامر المُطالَبة، والنتائج المعلّقة.

## 4. HTTPS

- في الإنتاج ضع nexus-api خلف TLS (Nginx/Caddy أو نفق) واضبط `InpBaseURL` بـ `https://`.
- MT5 WebRequest يدعم HTTPS أصلًا؛ فشل `-1` مع خطأ 5203 يعني مشكلة شهادة (استخدم شهادة صالحة من مرجع معتمد).
- لا تُرسل التوكن عبر `http://` في شبكة غير موثوقة — الصلاحيات كاملة على حسابك.

## 5. دورة الحياة

| الحالة | المعنى |
|---|---|
| `pending` | كتبها الـ executor بعد صفقة ناجحة — بانتظار مطالبة |
| `claimed` | سلّمها الـ API للإكسبيرت (مع طابع `claimed_at`) |
| `done` / `failed` | نتيجة الطرف (ticket/price/detail) مخزنة في `result_json` |

الأوامر المدعومة: `OPEN` (MARKET/LIMIT/STOP مع SL/TP وdeviation)، `CLOSE`/`PARTIAL_CLOSE` (تطابق بالرمز + الرقم السحري + تعليق `nexus:...`)، `MODIFY` (SL/TP؛ القيمة ≤0 = إبقاء الحالية).

## 6. استكشاف الأخطاء

| العرض | السبب/الحل |
|---|---|
| WebRequest err=4014 | العنوان غير مضاف لقائمة السماح (أضف الـ origin **بالضبط**) |
| 401 عند المطالبة | التوكن ملغى أو خاطئ — أنشئ توكنًا جديدًا (بعد 20 رفضًا يوقف الإكسبيرت المحاولات) |
| 409 عند المصافحة | التوكن مرتبط بطرف آخر — أنشئ توكنًا جديدًا لهذا الطرف |
| `unknown symbol` | الرمز غير موجود في طرفك (أسماء الوسطاء تختلف) — افتح الشارت مرة أولًا أو عدّل الاسم في الإعدادات |
| أوامر لا تصل | تحقق أن لديك توكن **نشطًا**: الطابور يوزّع على مستخدمي التوكنات النشطة فقط (`NEXUS_EA_QUEUE_DISABLED=1` يعطّل الكتابة) |

## 7. الحدود الأمنية

- الإكسبيرت لا يلمس إلا صفقاته (`magic = InpMagic`)، ويطابق الرمز/الاتجاه/التعليق عند الإغلاق والتعديل.
- الخادم لا يخزن التوكن الخام إطلاقًا؛ لا يوجد مسار يعيد إظهاره.
- كل نقاط EA محمية بالمصادقة وتحدد هوية المستخدم صاحب التوكن؛ لا يمكن لطرف رؤية أوامر مستخدم آخر.
