# عاجل للتركيب — اسحب آخر requirements.txt قبل pip install

أنت الآن تركّب المشروع. دفعتُ للتو دورة أمنية كاملة (T-006) غيّرت `requirements.txt` جذريًا. إن ثبّتّ من نسخة قديمة ستحصل على حزم تحمل 85 ثغرة معلنة ستنزعها لاحقًا — اجعل ترتيبك هكذا:

## الترتيب الصحيح

1. **قبل أي pip install**: `git pull --rebase origin main` — للتأكد أنك على أحدث `requirements.txt` (بعد commit دورة TC-SEC-06).
2. ثم ثبّت كما في البرومبت الموحد: `pip install -r requirements.local.txt` (يشمل torch CPU أولًا) ثم ما يلزم.
3. تابع تعليمة التحقق المحلي لـ T-001 في `MSG-20261105-1520-Z002` كما هي.

## ماذا تغيّر في المتطلبات (لعلمك فقط — لا تقرر شيئًا)

- **أُزيل**: `python-jose` (وتبعيته ecdsa) — غير مستوردة إطلاقًا؛ المصادقة تُنفَّذ حصريًا بـ PyJWT. كلاهما بلا إصلاح متاح لثغراته.
- **ترقيت كليًا**: عائلة langchain/langgraph إلى 1.x، mlflow إلى 3.18، transformers إلى 5.22، pyarrow إلى 26.
- إن ظهر لك أثناء التثبيت أي تعارض أو حزمة مفقودة، اكتب المشكلة في `outbox/` برسالة بنمط البروتوكول وسأعالجها فورًا.
